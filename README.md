# Sistemas Informáticos Industriales

## 📖 Descripción

Proyecto de programación de un juego de tenis para dos jugadores.

Práctica 1: toma de contacto con el entorno y entendimiento de los comandos básicos de UNIX, además de la programación del movimiento de las raquetas y esferas.

Práctica 2: generación del FIFO, mediante sus funciones básicas (unlink, mkfiko, open, read,write, close). Además hemos añadido una especie de contador en el que cuadno algún jugador llega a los 3 puntos se cierra el programa.
